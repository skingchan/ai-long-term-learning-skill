# AI-LTS interactive lesson contract

【Course】Sxx-Mxx-Lxx · title
【Where】stage / module / exact current step
【Why】target competency + real use
【Prerequisite recall】1–3 prompts
【Objectives】2–4 observable behaviors
【Pass rule】independent evidence required
【Teaching】intuition, rigorous explanation, limitations and misunderstandings
【Demonstration】1–2 solved examples with reasoning and verification
【Guided practice】ONE suitable prompt → STOP and await learner response
【Feedback】actual response → misconception → next-level hint / repair
【Independent transfer】new task and explanation → STOP and await answer
【Homework】required, optional challenge, deliverable, allowed help, rubric
【Decision】teaching / practicing / awaiting-assessment / passed / review-due
【Record delta】evidence, mistakes, assigned work, exact next turn

**Runtime rule:** The above is an eventual lesson record, not a demand to output all blocks in one turn. At a checkpoint, stop and wait. Do not fill evidence or grade slots before receiving work.
