# AI-LTS curriculum blueprint

**Project / version / revision date**
**Destination:** authentic final task and conditions for success
**Starting state:** verified / self-reported / unknown competencies
**Constraints and workload scenarios**
**Competency map:** ID | skill | prerequisite | evidence type | target mastery (0–4)
**Dependency graph:** foundational → advanced, parallel domains
**Stages:** ID | outcome | prerequisites | modules | authentic artifact | estimated range | Gate
**Modules:** ID | lessons | expected practice | resources | transfer task
**Detailed next 2–6 weeks:** lesson ID | objectives | prerequisite check | independent exercise | homework
**Project ladder:** micro → small → module → integrated → independent capstone
**Assessment plan:** lesson checks / module Gate / phase Gate / delayed review
**Resource list:** required / recommended / optional + direct task for each
**Version log:** reason, changes, retained evidence, next checkpoint

Only expand remote lessons as they become relevant; avoid a fictional fixed year-long timetable.
