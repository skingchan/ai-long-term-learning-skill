# AI-LTS 长期训练项目实例

这里的项目来自已经讨论或规划过的长期学习方向，用来说明**同一教学 Skill 如何针对不同能力目标设计不同课程、教学与考核**。它们不是实际成绩单、学员日记或“已经通过课程”的证明。

| 项目 | 核心目标 | 代表性交付物 |
|---|---|---|
| [软件工程](software-engineering.md) | 重建技术基础，掌握架构与 AI 协作开发 | 独立解释代码、测试、部署应用 |
| [数学](mathematics.md) | 知识结构、逻辑推理和独立解题 | 解题、推导、证明和迁移 |
| [英语](english.md) | 按场景改善听说读写能力 | 阅读写作、真实对话、听说证据 |
| [中国历史](chinese-history.md) | 历史时序、因果、史料批判 | 时间线、史料评估、专题论文 |
| [文学与创意写作](creative-writing.md) | 阅读分析、创作和迭代修改 | 短篇作品、编辑和评论 |
| [电子琴](electronic-keyboard.md) | 从零开始练习电子琴 | 琴键识别、节奏、演奏片段 |
| [互联网商业能力](internet-business.md) | 挖掘需求、获取流量、创造供给、验证变现 | 访谈、实验、漏斗、经济模型 |
| [交易与投资](trading.md) | 风险、研究、执行、复盘和统计判断 | 交易计划、样本与复盘记录 |
| [AI 独立游戏开发](ai-indie-game-developer.md) | 个人指挥 AI 工具开发与发行游戏 | 可玩游戏、测试记录和发布计划 |

## 正确使用案例

1. 按学习目标挑选案例，重点参考能力拆解、阶段任务与评价证据，不套用个别学习者的起点。
2. 再回到 `SKILL.md` 先诊断真正的学习者。
3. 对缺少原始完整课纲支持的示例，所列阶段属于**可修改的建议方案**。
4. 游戏开发只是九个例子中的一个，不是本 Skill 的所属类别。
